    decide below
    • Drawer — a right-hand sheet for details and forms, Ant's most used CRM pattern. Every part exists inside Modal 540:3823; what is missing is edge anchoring: a Placement axis. ½ wave.
    • Slider — the only genuinely new gap. Nothing draggable exists; the natural home is the filter UI (price, surface, distance). ½ wave, when that UI is designed.
    • Tree row — Tree and TreeSelect need a row that indents, expands and optionally checks; Wave 58 gives the nesting, this adds chevron + checkbox. ¼ on top.

    • Divider master — a bound 1px line with optional label, so lists and cards stop drawing their own. ⅛.

        Method and sources

        Ant side: the components overview of Ant Design 6.6.4 read live on 2026-09-15 (73 components, Ant's seven categories; List deprecated in favour of Listy 6.6.0; Masonry 6.0.0 and BorderBeam 6.4.0 are 6.x additions). The six Pro components, Ant Design X, Charts and Mobile are separate libraries and stay out. For the 14 near components and Slider, each component page's examples and API props were read the same day and turned into the feature rows of the deep-dive.

        DS side: the live census of every component set and standalone component taken for the DSI comparison the same day (Actions 7 sets + 3 · Forms 10 + 3 · Navigation 6 + 1 · Feedback & status 9 + 1 · Cards & patterns 8 + 6 · AI 10 + 2 · Data display 16 + 14 · Utilities 1 + 3; icon pages counted only).

        Evidence check: the CE and NDL censuses of the working file were searched for slider, range, tree, drawer, cascader, segmented, mention, divider: nothing. Pagination remains the only proven gap (local master, 31 uses).

        Limits: comparison by role and function, not prop by prop; Ant runtime behaviours (virtual scroll, async loading, animations) are marked as behaviours, not gaps. Effort figures are estimates in waves under the standard pipeline (mockup on WIP - Luca → Vai → master → QA strip → records).
